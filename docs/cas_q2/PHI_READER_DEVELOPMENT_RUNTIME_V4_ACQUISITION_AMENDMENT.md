# Phi development runtime V4 one-time acquisition amendment

Effective when committed, 2026-09-13. **CAS Q2 STATUS: NOT READY.**

This result-blind amendment overrides only the acquisition-attempt and maximum
runtime-budget clauses of `PHI_READER_REPLICATION_PROTOCOL_V1.md` and the
prospective namespace plus completed-call restart clauses in
`PHI_READER_DEVELOPMENT_RUNTIME_CONTRACT.md`. The blank V4 acquisition is the
sole cross-acquisition exception to that contract's prohibition on restarting
completed calls. Within V4 and every other individual acquisition, completed
calls remain permanently non-repeatable. Every scientific cohort, role, order,
model revision, seed, prompt, renderer, token limit, guard, parser, retrieval
rule, batch size, policy, endpoint and within-acquisition failure condition
remains unchanged.

V3 ended with a preserved ambiguous call intent as accepted in
`PHI_READER_DEVELOPMENT_RUNTIME_V3_FAILURE_ACCEPTANCE.md`. Repeating that call
as if it were the original invocation is forbidden. Importing, copying or
selecting the V3 prefix is also forbidden. Instead, this amendment authorizes
exactly one new acquisition from an empty namespace:

- canonical: `phi_reader_development_runtime_v4`;
- fixed replay: `phi_reader_development_runtime_replay_v4`;
- independent validation: `phi_reader_development_runtime_validation_v4`.

V4 is the sole prospective development acquisition eligible for later fitting
and analysis. It is a failure recovery acquisition, not a second seed, second
reader, robustness repetition or opportunity to select better text. V3 stays
excluded even if any V3 and V4 row happen to match. A V4 interruption or failure
may resume only while its namespace is unsealed, every event is paired and the
original executor verifies the exact executable freeze plus the complete
prefix. An unpaired event or terminal marker fails closed. This amendment does
not authorize V5 or any automatic additional attempt.

V4 must start at position zero and complete all 13,500 ordered development
traces: 40,500 logical Phi generations and 13,500 repair retrievals. Its already
fixed 180-trace replay adds 540 logical Phi generations and 180 repair
retrievals. Replay must reproduce all four selected canonical ledgers
byte-for-byte. The independent validator must reconstruct the complete semantic
and byte-level gate before development targets, scoring or ten reader-specific
fits may open. This amendment does not authorize test generation or test Gold.
Those stages require their separate original-protocol prerequisites; in
particular, test Gold remains closed until all fixed test actions and the
independent prelabel validation are sealed under section 5 of the original
protocol.

The original protocol's 94,500-generation development-plus-test ceiling is
amended only to disclose the failed acquisition overhead. If V4, its fixed
replay and the already planned test acquisition all later complete, the maximum
known logical Phi generations are 123,662:

`28,622 preserved V3 + 40,500 V4 + 540 V4 replay + 54,000 planned test`.

The unmatched V3 `a1` is reported separately as one call whose execution status
is unknown, making the physical-call upper bound 123,663 if it did execute. The
failed resume process adds one BGE load and one Phi load but no new scientific
generation or retrieval. Known repair-retrieval calls through V4 replay are
23,221 (`9,541 + 13,500 + 180`); later test repair calls remain those already
authorized by the original protocol. All actual tokens, forwards, elapsed time,
CUDA peaks and failures must be reported per process, never reconstructed as
zero and never presented as one uninterrupted run.

Before launch, commit this amendment, the V3 failure acceptance, the execution
entry point that binds both documents, the current handoff and evidence index.
Require a clean worktree and record that commit in V4's executable freeze. Run
the formal acquisition with Sol High. Preserve stdout and stderr externally
with their command, process identity, timestamps and final hashes. Completion
still requires the original 13,500-trace count, exact 180-trace replay and an
independent validator; successful acquisition alone is not scientific evidence
or CAS Q2 readiness.
