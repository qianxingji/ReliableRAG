Decision: **PASS_OFFICIAL_DISCOVER_DATA_CODE_POLICY_MAPPED_IMPLEMENTATION_GATES_OPEN.**

**CAS Q3 STATUS: NOT READY.** The official policy for the provisional
editorial-fit lead is now known. This record does not select the journal,
license the project, authorize distribution or claim full public neural
reproduction.

The Discover editorial-policy page was checked on 2026-09-14. It requires a
Data Availability Statement. It strongly encourages availability of datasets
supporting the conclusions and expects deposition where a community norm
exists. Restrictions on data that cannot be shared openly must be explained.
For third-party data, the restriction must be stated and review access must be
possible under a data-use agreement when legally and ethically permitted.

Previously unreported software or custom code described in a manuscript should
be available for testing by editors and reviewers. An appropriate Code
Availability Statement should give both the latest code link and the archived
version used in the manuscript, with a DOI or other unique identifier. The
publisher recommends Zenodo for GitHub archival.

Official source: <https://link.springer.com/brands/discover/policies>

## Project fit

The current deterministic anonymous aggregate ZIP is independently validated
and suitable for reporting-arithmetic review within its scope. It contains no
questions, answers, per-question outcomes, model weights or full neural
executor. It therefore does not satisfy a broad claim of complete public
end-to-end reproduction.

The versioned repository supplies project code, but no top-level project
license or license-bearing DOI archive exists. The private forensic artifacts
are hash pinned, but a journal-approved confidential access channel has not
been confirmed. Public distribution of the aggregate candidate remains
withheld.

The manuscript now names both data and code availability and states these
limits directly. If Discover Computing is selected, P0-G still requires the
owner license and legal holder/year, any institutional release approval, latest
and immutable archived code locations, a persistent identifier, compliant
access terms, review access for restricted evidence, and a newly built and
independently validated aggregate archive. These are release operations; they
do not require new scientific fitting or benchmark evaluation.
